Installer Akiba Suivi
sur un téléphone Android

Akiba Suivi marche déjà dans le navigateur, sans rien installer. Cette application sert surtout aux terminaux de caisse, où l'icône n'apparaît pas toujours sur l'écran d'accueil, et où l'on veut imprimer les reçus.

Télécharger l'application

3.4M · version du 12/11/2026

Pas à pas

  1. Appuyez sur Télécharger l'application. Le téléphone enregistre un fichier nommé akiba-suivi.apk.
  2. Ouvrez ce fichier, depuis la barre des notifications ou depuis le dossier Téléchargements.
  3. Le téléphone demande l'autorisation d'installer depuis cette source. Appuyez sur Paramètres, puis activez Autoriser cette source, puis revenez en arrière.
  4. Appuyez sur Installer, puis sur Ouvrir.
  5. L'icône Akiba Suivi reste sur l'écran d'accueil. C'est elle qu'on ouvre aux réunions.
Vos données sont conservéesSi le cahier était déjà ouvert dans le navigateur de ce téléphone, l'application retrouve les mêmes groupes, les mêmes membres et les mêmes réunions : c'est la même adresse, donc le même cahier.
L'application ne demande aucune autorisationNi réseau, ni position, ni contacts, ni photos. Tout reste dans le téléphone, et rien n'en sort sans un geste du bureau.
Contre la suppression par erreurUne fois installée, ouvrez Installer et protéger dans l'application et activez Empêcher la suppression. Le téléphone refusera alors de supprimer Akiba Suivi : il faudra d'abord revenir retirer la protection. Une suppression reste possible, mais plus par mégarde.
Pour imprimer les reçusSur un terminal avec imprimante, installez aussi RawBT depuis le Play Store : Akiba Suivi lui passe les tickets. Sans elle, les reçus se partagent par WhatsApp ou par SMS, comme avant.

Si l'installation est refusée

Certains terminaux demandent d'activer l'autorisation à l'avance : Paramètres › Applications › Accès spécial › Installer des applications inconnues, puis choisissez le navigateur et autorisez-le.
