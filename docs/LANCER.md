# Lancer Akiba

Développée par l'**Entreprise Sociale Ubora**.
Assistance : appel ou WhatsApp **0998 275 144** · contact@uborahub.com

## 1. Les deux adresses

| Sur le téléphone de… | Adresse |
|---|---|
| un **groupe** (bureau et membres) | **https://akiba.uborardc.com/** |
| un **animateur**, une **organisation**, l'**administration Ubora** | **https://akibas.uborardc.com/** |

Hébergées gratuitement sur GitHub Pages, en HTTPS. Les mises à jour se font en envoyant le code sur GitHub : les téléphones prennent la nouvelle version tout seuls, sans désinstaller et sans perdre les données.

## 2. Installer sur un téléphone ou une tablette
1. Avec du réseau, ouvrir l'adresse dans **Chrome**.
2. Toucher **« Installer »** (ou menu ⋮ → « Ajouter à l'écran d'accueil »).
3. Ouvrir depuis l'icône. Ensuite, **tout marche sans réseau**.

La **démonstration** de l'application du groupe est ouverte à tout le monde, sans code : AVEC fictives, codes secrets `1234`, carte de secours `2468-1357`. Akiba Suivi, lui, démarre **vide** : pas de faux groupes dans un espace professionnel.

## 3. Passer aux vraies opérations
Un téléphone qui travaille sur de vraies données doit être **validé par Ubora**, une seule fois. Il affiche son propre **code de huit signes** (par exemple `B6WE766A`) ; Ubora renvoie en retour :

- un **code court de huit signes**, qui se dicte au téléphone en vingt secondes ;
- ou le **code long signé**, par WhatsApp, par QR code ou par lien — plus sûr, à préférer dès qu'on peut envoyer un message.

Les deux ne valent que pour le téléphone qui les a demandés.

### Ouvrir le compte d'une organisation
Sur **Akiba Suivi**, en trois temps :
1. L'organisation écrit qui elle est : nom, province et territoire, responsable, téléphone.
2. Akiba prépare la demande — par WhatsApp, ou en QR code à montrer à un responsable d'Ubora. Ubora vérifie et renvoie un code de validation. **Seule cette étape demande du réseau.**
3. Le responsable choisit son code secret, et le compte existe. Il ajoute ensuite ses animateurs.

### Les autres cas
- **AVEC autonome** : créer directement le groupe sur l'application du groupe, sans animateur ni organisation.
- **Téléphone d'une AVEC accompagnée** : « Recevoir une AVEC » avec le fichier et le code envoyés par l'animateur. La validation arrive avec le fichier.

## 4. Avant le lancement réel
- **Imprimer la [fiche de terrain](FICHE-TERRAIN.html)** et la suivre : elle liste ce qu'il faut emporter et les quatre points qui dépendent du matériel (terminal thermique, QR des cartes, point GPS, ouverture d'un compte).
- **Les données restent dans chaque téléphone.** Faire une **sauvegarde chiffrée chaque semaine** (Plus › Installer et sauvegarder) et **garder le cahier papier** pendant toute la phase pilote.
- **Faire relire les traductions** (lingala, swahili, kikongo, tshiluba) et traduire les langues du Sud-Ubangi avec l'écran « Langues ».
- **Vérifier la version** : la date est écrite en bas de chaque écran. « Chercher une mise à jour maintenant » la compare avec ce qui est en ligne.
- **Les codes de validation ont une date de fin.** Pour prolonger, l'administrateur crée un nouveau code.
