Les quatre points à éprouver

Ce sont les seuls que personne n'a pu vérifier au bureau : ils dépendent de votre matériel et du terrain.

1 · Le terminal thermique

  • Un reçu de réunion sort entièrement, lisible
  • Les cartes de membre sortent sur la bande de 58 mm
  • Les accents et les montants sont justes

Si rien ne sort : notez la marque et le modèle exacts du terminal.

2 · Les cartes et leur QR code

  • Dix cartes sortent sur une feuille A4 et se découpent droit
  • « Vérifier une carte » lit le QR depuis un autre téléphone du groupe
  • Essayé avec le téléphone le plus bas de gamme du groupe
  • Essayé en plein soleil, puis à l'ombre
  • Une carte d'un autre groupe est bien refusée

3 · Le point GPS

  • Pris dehors, à ciel ouvert — compter jusqu'à une minute et demie
  • Essayé sous les arbres : noter si le point vient, et en combien de temps
  • Essayé dans une salle : noter le message affiché

Le réseau n'est pas nécessaire : le téléphone lit les satellites.

4 · Ouvrir un compte d'organisation

  • L'ONG remplit ses renseignements et prépare sa demande
  • La demande arrive par WhatsApp ou par QR scanné dans l'espace admin
  • Je crée le partenaire et le code dans l'espace administrateur
  • Je dicte le code court de huit signes au téléphone — il est accepté
  • Le même code dicté à un autre téléphone est bien refusé
  • L'ONG choisit son code secret, le compte existe, elle ajoute un animateur

Puis une vraie réunion, du début à la fin

  • Créer le groupe avec l'assemblée réunie, règlement et bureau compris
  • Tenir la réunion en entier : présences, comptage, épargne, remboursements, crédits, amendes, clôture à trois clés
  • Remettre les reçus aux membres
  • Envoyer les données à l'animateur, et vérifier qu'elles arrivent
  • Comparer avec le cahier papier, franc pour franc

Si quelque chose casse, notez trois choses

L'écran où vous étiez · ce que vous veniez de toucher · la date de version en bas d'écran.

Avec ces trois choses, le défaut se retrouve sans deviner. Une capture d'écran vaut mieux qu'une description.
